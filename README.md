Om projektet
  Detta är min portfolio där jag visar:
    - **Om mig** – kort presentation
    - **Projekt** – plats för framtida arbeten
    - **Kompetenser** – HTML, CSS, C#/.NET
    - **Kontaktformulär** – byggt med [FormSubmit](https://formsubmit.co)

---

Installation
  1. Klona repot:
     ```bash
     git clone https://github.com/nimali-rgb/webbportfolio.git
  2. Öppna projektet i din editor (t.ex. VS Code).
  3.Starta en lokal server (t.ex. Live Server) för att se sidan i webbläsaren.

Användning
  -Navigera via menyn (Om mig, Projekt, Kompetenser, Kontakt).
  - Skicka meddelanden via kontaktformuläret.
  - Se referenser och sociala länkar i footern.

 Tekniker

  - FormSubmit – enkel hantering av formulär
